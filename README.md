# SnapText

SnapText is a browser extension for capturing text from a selected
screen area using OCR. It supports English and Bengali text extraction.

## Status

Version: 1.0.0
Distribution: Manual installation for testing
License: Proprietary

## Features

- Capture browser content and select an area.
- Extract text using locally bundled OCR assets.
- Copy extracted text and use the available save workflow.
- English and Bengali OCR language data.

## Install in Chrome or Brave

1. Download the project ZIP from the project's GitHub Releases page.
2. Extract the ZIP to a permanent folder.
3. Open `chrome://extensions/` in Chrome or `brave://extensions/` in Brave.
4. Enable Developer mode.
5. Select **Load unpacked**.
6. Choose the extracted folder containing `manifest.json`.

Keep that folder in place while using the extension.
